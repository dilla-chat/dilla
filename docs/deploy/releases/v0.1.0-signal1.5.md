# dilla v0.1.0-signal1.5

A release on top of [v0.1.0-signal1.4.1](v0.1.0-signal1.4.1.md). It adds the server side of the desktop apps, fixes Bot
interactions on clients whose clock runs behind, hardens security, and removes Spotify. The release includes `dillad`
(with the web client), `dillabot`, their matching core modules, installers and checksums.

## What's new

- **Desktop sign-in routes.** The server now serves `/desktop-auth/*`, the passkey and OIDC hand-off the desktop apps
  use: the app opens the system browser at `/desktop-auth/<id>/`, the browser completes the ceremony, and the app
  collects the result. The routes are same-origin, rate limited and carry a strict Content-Security-Policy.
- **The repository moved** to github.com/dilla-chat/dilla. Old URLs redirect, and the Go module was renamed to match.

## What's fixed

- **Bot interactions work with a client clock up to 5 s behind the server** (PR #145). Before, a Bot command from such
  a client could be refused as not yet valid.
- **Security hardening** (PR #142).

## What's removed

- **Spotify.** The Bot no longer plays Spotify. The `dilla-spotify-helper` binaries are gone from the release,
  `install.sh` no longer has `--spotify-helper`, and `dillabot doctor` no longer checks it.
- On an upgraded host the old helper binary (`/usr/local/libexec/dilla-spotify-helper`) and the
  `spotify_helper_executable` key in `bot.toml` are leftovers. You can remove both; the Bot ignores them.

## Versions and compatibility

| Component | This release | signal1.4.1 |
|---|---:|---:|
| Server database schema | 55 | 55 |
| Browser client store schema | 13 | 13 |
| Negotiated wire version (web) | 5 | 5 |

There are no new database migrations.

## Deploy order

The same as [signal1.4.1's](v0.1.0-signal1.4.1.md#deploy-order): check that no call is live, upgrade `dillad`, ask
everyone to reload their tabs, then upgrade `dillabot` and run
`sudo -u dillabot dillabot doctor --config=/etc/dillabot/bot.toml --youtube`.

The reverse proxy must pass `/desktop-auth/*` to `dillad`. A proxy that forwards the whole host (Pangolin or Traefik
with a host rule) needs no change.

## Rollback

Rolling back to signal1.4.1 is a plain binary rollback. Spotify then needs the helper reinstalled
(`install.sh --spotify-helper` of that release).

## Known limits

- The desktop app needs this server version or later for passkey and OIDC sign-in. Against an older server it says the
  server needs an update.
- Otherwise the same as [signal1.4](v0.1.0-signal1.4.md#known-limits).
