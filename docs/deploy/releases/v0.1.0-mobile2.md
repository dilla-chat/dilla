# dilla v0.1.0-mobile2

A release on top of [v0.1.0-mobile1](v0.1.0-mobile1.md). It is the first release with the mobile preview apps. The
`v0.1.0-mobile2` Android APK was built by hand from this tag and shared directly: it is not attached to this release,
because releases are immutable once published and the automated APK build came after it. iPhone builds go to
TestFlight. The release includes
`dillad` (with the web client) and `dillabot`. The server and the desktop app are unchanged apart from the web client
fixes below.

## Mobile app

- **Install.** See [dilla on iPhone and Android](../../user/mobile.md#install). On Android, ask the instance owner for the
  hand-built `v0.1.0-mobile2` APK; from the next release on, the signed APK and its `.sha256` are assets of each
  release. iPhone builds go to TestFlight; ask the instance owner for the link.
- **Fixed: a blank page on Android after switching or adding an instance.** Capacitor Android 8.6.0 could deliver a
  page's first plugin answer to the page before it after an in-app navigation, so the new page waited forever
  (upstream [ionic-team/capacitor#8382](https://github.com/ionic-team/capacitor/issues/8382)). The app carries a
  patch until Capacitor ships the fix, and shows an error screen with **Try again** and **Switch instance** instead of
  a blank page if the shell does not answer within 10 seconds.
- **Fixed: no visible way back from Threads or Members on iPhone.** The sheet's back and close controls sat under the
  status bar; they now clear it.
- The app is still a preview: no push notifications, no calls in the background, and its data is not backed up. Keep
  your browser or desktop device and your recovery key.

## Server

No server changes. The web client served by `dillad` gains the two fixes above (the safe-area fix shows in a phone
browser only where the browser reports a status-bar inset).

## Versions and compatibility

| Component | This release | mobile1 |
|---|---:|---:|
| Server database schema | 55 | 55 |
| Browser client store schema | 13 | 13 |
| Negotiated wire version (web) | 5 | 5 |
| Desktop app | 0.1.0-beta.3 | 0.1.0-beta.3 |

There are no new migrations and no configuration changes. Rolling back to mobile1 is a plain binary rollback.
